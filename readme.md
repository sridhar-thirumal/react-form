Aim:
Build a responsive sign up form with react and tailwind with the following fields and validations:
 
First Name
- Required
- Should not be longer than 25 characters
 
Last name
- Required
- Should not be longer than 25 characters
 
Age
- Required
- Should be greater than or equal to 18
- Should contain only numeric values
 
E-Mail
- Required
- Valid email id
 
Password
- Required
- Should atleast have 8 characters with atleast one capital letter
 
Confirm Password
- Required
- Should be the same the password field
 
Note:
Run validations on input change event and on form submit event.
 
When clicked on a label, the relevant input field should be focused.
 
Provide a toggle button to reveal and hide the password for "Password" and "Confirm Password" fields.
 
Show error message below the input field when validation fails.
 
When validation for all the fields succeed, navigate to a new page and show a success message.
